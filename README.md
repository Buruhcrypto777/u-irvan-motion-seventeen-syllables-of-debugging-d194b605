Entry for the make.fun bounty [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

A pure-stdlib Python program (`main.py`) writes one haiku about debugging to `/output/entry.txt` — three lines in the 5-7-5 syllable shape. The haiku:

> stack trace scrolls on by
> one log line glows in the dark
> it was my typo

71 characters. The program runs offline and produces byte-identical output on every run.
